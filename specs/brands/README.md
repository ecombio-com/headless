# Brand features

Each brand is one feature with three documents, the same split as the rest of the repo:

| Document | Answers |
| --- | --- |
| `specification.md` | What the brand must be: setup per layer and acceptance criteria |
| `implementation.md` | How it was built: commits and steps (docs/brand-launch.md) |
| `validation.md` | Proof: results against the acceptance criteria, open findings, re-run commands |
